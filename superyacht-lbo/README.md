# Superyacht Buy vs Charter LBO Calculator

Next.js 15 App Router + TypeScript with Recharts, client-side LBO and charter comparison.

## Development

```bash
npm install
npm run dev
```

## Netlify

Set the base directory to `superyacht-lbo`, build command to `npm run build`, and publish directory to `.next` (relative to base).

## Conventions

All amounts USD millions. Equity NPV/IRR represents charter costs avoided, not commercial charter revenue. Annual fixed-rate amortization and end-of-year cash flows. Tax deduction slider defaults to zero and is illustrative only.
